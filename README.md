Anki Add-on for exporting a video and audio for tomorrow's cards

After finishing today's set of cards for the Kaishi 1.5k Anki deck, you can get
familiar with seeing the sentence and hearing the sentence audio for tomorrow's
set of cards via exported video. There's also an exported audio if you only want
to listen.

Screencast: https://www.youtube.com/watch?v=eJXswZcyAOc
