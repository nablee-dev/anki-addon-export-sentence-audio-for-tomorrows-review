## Audio file + .lrc file

After sampling a few exported file formats, I settled on audio file + .lrc file. Just from a glance seems to be the most standard/supported way to do synchronized lyrics for files locally stored on an iPhone.

Other synchronized lyrics format that came up but I didn't explore:

* SYLT for mp3 files
* TTML. E.g. https://help.apple.com/itc/videoaudioassetguide/en.lproj/static.html#itca96ba3a47

One of the drawbacks with audio file + .lrc is that it's not supported for local files for YouTube Music app or the Apple Music app.

## Rejected idea of exporting epub file

Exporting epub file was a cool idea since ebook reader apps can highlight the sentence text being read aloud through the sentence audio.

The main drawback is that the ebook reader apps I sampled do not loop the book. Additionally, it would have been nice if an official Apple app supported the exported epub file. But there are some limitations with Apple Books "read aloud" feature. 

> "Note that read aloud content is supported only in fixed-layout books."

Apple Books Asset Guide 5.3.1 > Read Aloud Books - https://help.apple.com/itc/booksassetguide/en.lproj/static.html#apd8c781091adb54

## Rejected idea of exporting video file

Exporting a video file was a nice idea since I can just use the native Photos app, and that app allows to loop. I could also AirPlay the video to a TV also.

The main drawback with the Photos app is that as soon as I locked my phone, the audio would not continue to play in the background. I tried the VLC player app on iPhone, and it did play the video in the background. It was also nice that it had a picture-in-picture player when I used another app.

The drawback with the video export is that the orientation is fixed. If I wanted to use my phone portrait mode, the text would be very tiny.

## Rejected idea of specialized language apps

Specialized language apps like LingQ have a karaoke feature that does exactly what I'm looking for. It's also nice that it just magically worked on both my MacBook and iPhone. When I locked my phone, it plays in the background. I don't have to shop around for the best app that works with a certain file format. The main drawback is that I have to pay for it.
